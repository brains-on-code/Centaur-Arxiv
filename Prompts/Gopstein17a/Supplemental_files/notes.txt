Study: Gopstein17a / Atoms of Confusion 2016 Snippet Study

Source database: Supplemental_files/confusion.db

Tables used:
- code: used for task snippets, reference answers, type, and pair information.
- UserCode: used for participant answers, correctness, duration, timestamps, and task order.

Columns used from code table:
- ID as original_code_id
- Code as code snippet
- Answer as reference answer
- Type as confusing/non-confusing type
- Pair as paired snippet ID

Columns used from UserCode table:
- UserID as original participant ID
- CodeID as task ID
- Answer as participant answer
- Correct as correctness
- rank as task order
- Duration and TimeTotal as timing metadata

Original UserID values were mapped to participant numbers 1, 2, 3, etc.
The mapping is stored in participant_file_mapping.csv.
